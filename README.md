# Домашние задания к курсу "Архитектура платформ машинного обучения"

1. Создать форк проекта
2. Реализовать задания в своем форке

### Формат сдачи:

 * Система сборки CMake.
 * Проект должен собираться стандартными командами cmake + make или предоставить sh скрипт для сборки.
