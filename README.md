# Домашние задания к курсу "Архитектура платформ машинного обучения"

1. Создать форк проекта
2. Реализовать задания в своем форке

### Формат сдачи:
 * Ссылка на репозиторий(форк) + ФИО автора, предоставить права доступа к ветке.
   * Если нужны комментарии, тогда открывается PR в основной репозиторий из форка, и преподаватель указывается как Reviewer.
 * Система сборки CMake.
 * Проект должен собираться стандартными для CMake проектов командами:
  ```bash
git clone <branch_name>
cd <branch_name>
mkdir build
cd build
cmake ..
cmake --build .
  ```
  * Проверка проходит в окружении описанном в следующем [Dockerfile](https://git.hse-shift.ru/ml-platform-arch/practice/-/blob/main/docker/Dockerfile).
